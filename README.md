# Simple 2D platformer (LibGDX)

My first LibGDX project. Made to understand how game physics works.

## What's in there: 

- Character moves left/right 
- Can jump (has a bug)
- 3 platforms with collision
- Clean code structure (entities/, screens/, utils/, world/)

## Why this exists

- Understand game loop basics
- Figure out physics and collisions 
- Learn to work with LibGDX
- First "step" into game dev

That's it. Nothing fancy.
